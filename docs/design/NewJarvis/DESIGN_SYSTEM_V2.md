# 设计系统 v2：深色「驾驶舱」

- 状态：**草案**，取代 [DESIGN_SYSTEM.md](../../DESIGN_SYSTEM.md) 的浅色基线
- 数值来源：Figma Page 2 的 1329 个节点实测统计（见 [figma/tokens.md](figma/tokens.md)）
- 适用面：中控（桌面浏览器）+ 手表（360×480 实机，展讯 8521 / Android 8）

---

## 1. 基线

| 项 | 中控 | 手表 |
| --- | --- | --- |
| 设计稿画布 | 1040 × 视高（最长 2990） | 400 × 540（含 40 圆角设备框） |
| 实机/实屏 | 响应式，设计基准 1040，有效 960–1280 | **360 × 480** |
| 主题 | 仅深色 | 仅深色（极暗模式为其子集） |
| 密度 | 表格 + 分区，信息密度高 | 卡片流，一屏一个判断 |

浅色主题在 v1.0 **不做**。现有 `ThemeMode` 的浅/深/跟随三态降级为"深色 + 极暗"两态。

## 2. 色彩

### 2.1 结构色

| 令牌 | 色值 | 用途 | 节点计数 |
| --- | --- | --- | --- |
| `bg-base` | `#0B0E11` | 页面最底 | 44 |
| `bg-deep` | `#0D1115` | 表格斑马、内嵌区块 | 19 |
| `surface` | `#11161B` | 卡片、面板 | 78 |
| `surface-raised` | `#181E24` | 悬浮卡、输入框、引用块 | 62 |
| `line` | `#2B333B` | 分隔线、卡片描边（最高频结构色） | 191 |
| `line-strong` | `#242A30` | 表头、强调描边 | 42 |

### 2.2 文字色

| 令牌 | 色值 | 用途 | 节点计数 |
| --- | --- | --- | --- |
| `text` | `#EDF0F2` | 结论、标题、正文主色 | 438 |
| `text-secondary` | `#B2BBC3` | 次级说明、表体 | 310 |
| `text-muted` | `#78848F` | 标签、脚注、坐标（最高频弱色） | 422 |
| `text-faint` | `#96A0AA` | 极弱提示、"脱敏演示"类标记 | 63 |

### 2.3 语义色（四档门控与风险等级的唯一定义）

| 语义 | 前景 | 背景底 | 对应状态 | 计数 |
| --- | --- | --- | --- | --- |
| 高风险 / 待许可 / 禁止 | `#EE9692` | `#301E20` | 高风险·等你、每次确认、失败 | 83 / 24 |
| 建议 / 确认一次 / 降级 | `#E3C17B` | `#2C261A` | 建议·确认一次、服务降级、低电量 | 74 / 18 |
| 自动 / 已完成 / 在线 | `#83C7A3` | `#14271F` | 自动·已处理、已完成、在线 | 45 / 14 |

**规则**：语义色只允许出现在"状态胶囊、描边、左侧 2px 状态条、关键数字"四处，不得整块铺色。
高风险卡是唯一允许整卡染色底（`#301E20`）的组件，因为它是全系统唯一需要"停下来看"的东西。

## 3. 字体

| 角色 | 字体 | 用途 |
| --- | --- | --- |
| 正文/标题 | **Noto Sans SC** 400 / 500 / 700 | 全部中文与说明文字 |
| 数据/编号 | **IBM Plex Mono** 400 / 300 | 章节编号 `01 / ATTENTION & AUDIT`、ID `M-021`、时间 `09:41:02`、JSON |

## 4. 间距与圆角

```
圆角  6   按钮、输入、小卡片、状态胶囊容器（180 次，主力）
      12  大卡片、面板（49 次）
      2   细条、进度、标签底（40 次）
      40  大药丸（9 次，仅少量主按钮）
间距  中控：区块 32–40，卡片内 16，表格行 12–14
      手表：页面左右 20，模块间 20，卡片内 14，行间 7
描边  统一 1px；高风险卡 1px 语义色；不使用阴影
```

**无阴影、无渐变、无模糊**。层次只靠 `bg-base → surface → surface-raised` 三级明度和 1px 描边区分。

## 5. 画布换算（重要）

手表设计稿是 400×540，实屏是 360×480。**不能整体等比缩放**，否则 12 号正文变成 10.8，
在 1.4 英寸屏上不可读。规则如下：

| 对象 | 规则 |
| --- | --- |
| 横向尺寸、间距、内边距 | 乘 **0.90**（400→360），结果取偶数 |
| 纵向位置 | 乘 **0.89**，允许自然溢出到滚动区 |
| 字号 | **不缩放**，直接用实机字阶（10/11/12/14/16/17） |
| 行高 | 按实机字号重算，中文 1.55–1.7 倍 |
| 固定高度容器 | 改为 `wrap_content`，禁止硬编码稿内高度 |

**副作用要接受**：稿内首屏放得下 4 张注意力卡，实机因字号不缩、行高变大，首屏通常只能放
2–3 张，余下靠滚动。这是正确取舍——可读性优先于"一屏塞满"。

中控按 1040 设计，实现用响应式栅格：`min 960 / 基准 1040 / max 1280`，三栏表格表在 960 以下
改为横向滚动，不压缩字号。

## 6. 组件规格

### 6.1 状态胶囊（Pill）

```
高 22（手表 20）；左右内边距 10；圆角 2（贴边样式）或 6（独立样式）
字号 11；左侧 4px 圆点若表示风险等级
四种语义：高风险(红底) / 建议(琥珀底) / 自动(绿底) / 中性(线描边)
```

### 6.2 注意力卡（AttentionCard）

手表主组件，结构固定四行：

```
[状态胶囊]                         [为什么 ›]
标题（16，500，最多两行）
动作行（12，语义色，一个主链接）或 [主按钮][次按钮]
```

风险等级通过**左侧 2px 竖条**表达，不通过整卡染色（仅高风险例外）。

### 6.3 四层依据块（EvidenceStack）

```
01  结论            正文 12，结论一行说清"发生了什么、可否撤销"
─────────────────────────────
02  判断与依据      带置信度与风险等级，一行
─────────────────────────────
03  引用            记忆/事件/工具各一组，等宽 ID + 可点
─────────────────────────────
04  原始输入与门控  语音片段/ASR 原文/通知原文/门控记录，默认折叠
```

层与层之间用 `line` 1px 分隔，层标签用 `text-muted` + 等宽数字编号。

### 6.4 表格（中控专用）

```
表头：11，text-muted，无底色，下描边 line-strong
行：  12–13，text-secondary，垂直对齐 top
斑马：无；用 1px 分隔线（bg-deep 仅用于嵌套表）
数字列右对齐，ID 列等宽字体
```

### 6.5 按钮层级

| 层级 | 样式 | 使用场景 |
| --- | --- | --- |
| 主危险 | 语义红描边 + 红字，底 `#301E20` | 确认发送、确认销毁 |
| 主安全 | `surface-raised` 底 + `text` 字 | 取消、暂时保留 |
| 次 | 纯文字 + `line` 描边 | 查看依据、编辑 |
| 文字链 | 无边框，`text-secondary` 或语义色 | "为什么 ›"、"查看留痕 ›" |

**两个按钮并排时，危险动作永远在右侧**，且危险按钮的宽度不小于次要按钮。

### 6.6 状态点与波形

```
在线点    7px 圆，绿；离线 红；等待 琥珀
感知波形  5 根 3px 竖条，高度 4–14 随机，仅 ASR 活跃时动画
连接条    中控设备页的 15 分钟条形图，1 格 = 1 分钟，色阶表达在线/降级/离线
```

## 7. 动效

只允许两种，总时长 ≤ 180ms，`ease-out`：

1. 卡片出现：透明度 0→1 + 上移 4px。
2. 依据展开：高度动画（或直接切换，手表上建议直接切换以省电）。

不使用弹簧、视差、发光、毛玻璃。手表上任何持续动画都必须能被系统低电量策略关闭。

## 8. 可读性约束

- 正文对比度 ≥ 7:1（`#EDF0F2` on `#11161B` 满足；`#78848F` 只能用于辅助信息）。
- 极暗模式：整体亮度再降一档，`bg-base` 保持 `#0B0E11` 不变，只降低卡片与文字亮度上限，**不改变语义色的辨识度**。
- 触摸热区 ≥ 44×44（手表），视觉高度可小于热区。
- 中文不断词断行导致歧义（如"未/发送"），关键动词不与否定词分处两行。

## 9. 禁止项

- ❌ 渐变背景、彩色大色块、发光描边
- ❌ 用颜色表达"重要"而不用文字（色盲不可读）
- ❌ 用"系统正在执行复杂流程"类文案填空状态
- ❌ 深色下使用纯黑 `#000`（与 OLED 边界融合，失去卡片轮廓）
- ❌ 字号小于 11 的中文正文
