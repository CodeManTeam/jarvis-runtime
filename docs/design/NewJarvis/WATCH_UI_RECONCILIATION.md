# 手表 UI 与原稿的逐屏对照

- 对照对象：Figma `Page 2` 的 9 个手表帧（2x PNG 见 [figma/png/](figma/png/)）
- 实现对象：`watch-client/app/src/main/res/layout/*.xml` 与 `MainActivity.java`
- **未验证**：真机 360×480 的实际渲染。没有实物手表与模拟器，本文件只做**结构级**对照，
  像素级差异必须在真机上复核。

## 0. 已知的系统性偏差

| 项 | 原稿 | 实现 | 说明 |
| --- | --- | --- | --- |
| 画布 | 400×540 | 360×480 | 布局按 0.9 缩、**字号不缩**（12 号缩到 10.8 不可读） |
| 页面边距 | 24（稿内） | 20 | 沿用旧基线，未按 0.9 改为 22，差 2dp |
| 时钟 | 62（稿内） | 62sp | 不缩放，因此在大屏稿里占比更小 |
| 返回 | 原稿无 | 每屏加了返回 | 设备只有触屏、无按键，必须有返回入口 |
| 离线/降级/极暗 | 各为独立整屏 | 首页状态卡 | 视为同一屏的互斥状态；结构等价、形态不同 |

## 已修正

| # | 项 | 证据 |
| --- | --- | --- |
| 1 | 首页补大时钟与日期 | `idle_clock` / `idle_date`，随 15 秒节拍更新 |
| 2 | **修掉真 bug**：时钟更新时顺带重绘整个注意力流，滚动位置每 15 秒被重置 | `updateStatusBarClockAndBattery()` 不再调用 `renderAttentionStream` |
| 3 | 首页「抬腕详情」折叠区 + 网络行 + 蓝牙/蜂窝 + 同步时间 + 感知说明 | `idle_details*` 六个视图；网络实测 `ConnectivityManager`，同步时间取**真实**最后一次成功拉取 |
| 4 | 注意力流底部「上滑看更多 · 最近同步 HH:mm」 | `attention_footer`，未同步时隐藏而不是显示假时间 |
| 5 | 页面边距 20 → 22（按 0.9 换算） | `space_page_h` |

## 一个必须说清的边界

本源文件是把"像不像"变成"差在哪"的**结构级清单**，不是像素级验收。
没有实物手表与模拟器，任何"已经一致"的说法都只能是结构层面的。
