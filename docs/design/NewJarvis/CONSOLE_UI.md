# 中控 UI 规格（5 页）

- 状态：**草案**，取代现有 7 项侧栏结构（[console/index.html](../../../console/index.html)）
- 设计稿宽度 1040，响应式 960–1280
- 原文案与坐标：[figma/texts.md](figma/texts.md)

## 总体框架

```text
┌─ 顶栏（固定）───────────────────────────────────────────────┐
│  ◱ JARVIS  个人中控台      ● 在线 · 感知中   ● 等待你 1   ● 脱敏演示 │
├─ Tab 栏（固定，5 项平级）──────────────────────────────────────┤
│  活动流   Agent 编排   记忆库   权限门控   设备与模型              │
├─────────────────────────────────────────────────────────────┤
│  01 / ATTENTION & AUDIT                     2026.10.24 / 09:41 CST │
│  宣言式标题（34，500）                                            │
│  一句副标题（14，弱色）                                           │
│  ────────────────────────────────────────────────────────  │
│  页面内容                                                        │
└─────────────────────────────────────────────────────────────┘
```

**规则**

1. **五个 tab 平级，无侧栏**。侧栏在 v1.0 取消；现有"AI 对话"不占 tab 位（去向见开放问题）。
2. **每页固定"编号 / 英文域 + 时间戳"** 的等宽小节头，是整个中控的识别符。
3. **每个 tab 都有一个宣言式主标题**，句子本身表达该页的价值主张，不是"XX 管理"。
4. **顶栏三个状态灯**：在线（绿）、等待你 N（琥珀）、脱敏演示（弱色）。脱敏标记常驻，除非接入真实数据。
5. 所有表格**数字右对齐、ID 用等宽字体、状态用胶囊**，行内不放操作按钮超过 3 个。

### 执行计划（步骤表，可折叠附件子步骤）

每步固定五要素：`序号 + 标题 + 状态胶囊 + 说明 + 时间/工具/幂等键`。

| 状态 | 表达 |
| --- | --- |
| 已完成 | 绿胶囊 |
| 失败后重试成功 | 琥珀胶囊，且必须同时显示原错误 |

| 未开始 | 弱色，说明中写清触发条件与禁止项 |

## 04 权限门控 · `8:10551`

> **信任能力，不交出边界。**
> 授权总是带着能力、范围与有效期。受信 Agent 也不能绕过任何高风险的逐次许可。

**当前实现对应**：**无**（只有"忽略规则"，与本页无关）。

| 档 | 说明 |

### 高风险操作（逐次许可，不可降级为自动）

顶部固定一张当前待办卡（同活动流的高风险卡），下面是**类别总表**：

| 高风险类别 | 当前门控 | 范围与不可逆边界 |
| --- | --- | --- |
| 外发消息 | 每次确认 | 每条消息与附件；外部送达后不承诺可撤回 |
| 财产 / 支付 | 每次确认 | 对象、金额、币种逐项核对 |

| 自迭代 | 每次确认 | 仅沙箱生成差异；部署前再次审阅测试与回滚方案 |
| 远程配置 / 执行 | 每次确认 | RCE 默认禁止；白名单配置逐次许可；任意命令不能凭信任解锁 |

## 05 设备与模型 · `8:10782`
