# Jarvis 手表设计系统

版本：v0.3，2026-10-03  
设计画布：360×480；物理像素不能直接视为 dp，真机 DPI 待测。

以下尺寸是图稿设计单位，Android 转换需校准，不能混用裸 px、dp 和 sp。
英文 Roboto，中文 Source Han Sans；未附字体文件，当前系统回退不能声称已精确还原。
标题 16，模块标题 12–13，正文 12–14，辅助/时间 10–11；字距 0。
原 SVG 弹窗圆角为 16，活动卡 10，按钮 6；以原稿为准，不使用旧版笼统圆角范围覆盖。
竖屏可滚动，主页加二级页，无侧栏和底部导航。当前先以浅色示意图为唯一验收基线。

## 3. 圆角

- 普通输入和按钮：6–8 设计单位。
- 主活动卡片：10 设计单位。
- 弹窗：16 设计单位。
- 不使用大面积胶囊和强阴影。

## 4. 图标

使用 Material Icons VectorDrawable：

- `light_mode`：Jarvis 状态图标。
- `settings`：设置。
- `graphic_eq`：ASR 波形。
- `history`：活动日志。
- `notifications`：通知权限。
- `qr_code_scanner`：扫码配置。
- `check`：接受。
- `close` 或 `schedule`：暂不。
- `expand_more`：展开。

图标颜色默认使用 `#79736B`，主动状态使用 `#B96C50`。

## 5. 组件

### ActivityRow

时间列 + 文案列，不带卡片边界。

### ActivityCard

用于需要解释、等待用户决定或可展开的活动。

### StatusHeader

图标、Jarvis、动态运行状态。

### ToggleRow

标题、副标题、真实开关状态。

### DetailSection

用于活动详情、来源、AI 判断、结果和操作。

## 7. 首页验收基线

- 设计画布固定为 360×480，左右边距 20。
- 首页首屏依次展示状态头、服务器配置、AI 介入、实时感知、AI 活动和两条时间线内容。
- 首页可以滚动；不使用底部导航、侧栏或桌面端宽布局。
- 活动主卡默认只展示摘要；展开后才展示门控决定、工具调用、来源和结果。
- 所有卡片状态来自 Activity 数据，不从文案猜测“已记录”“已完成”。
- 普通日志使用无边框时间线行；需要用户决策或存在风险的内容使用独立卡片。
- 真机验收重点是中文字体、360×480 裁切、触摸区域、滚动性能和低亮度可读性。

## 6. 交互语气

- 短句。
- 不使用技术错误码作为主文案。
- 不用“系统正在执行复杂流程”之类解释。
- 优先显示事实：
  - `已记录「周五取快递」`
  - `等待你的决定`
  - `你暂不接受提醒`
  - `已完成`
  - `暂时离线，稍后自动重连`
