# Jarvis 手表 UI 排版与交接方案

版本：v0.1  
目标设备：展讯 8521，Android 8，360×480 竖屏手表

## 1. 设计目标

Jarvis 是低打扰的个人秘书与第二大脑。首页只回答三件事：现在是否在感知、最近识别到了什么、是否有一件需要用户决定的事。页面保持安静、留白充足、信息密度低；详细过程进入日志详情，不把调试信息堆在首页。

固定设计画布为 360×480，运行时允许纵向滚动，但不做桌面端式自适应布局。页面只使用主页面和二级页面，不使用底部导航或侧边栏。

## 2. 页面地图

```text
首页
├─ 远端服务器配置 → 设置页
│  ├─ 扫码配置
│  ├─ 手动地址 / Token
│  ├─ 连接状态
│  ├─ AI 与感知设置
│  └─ 权限入口
├─ AI 活动主卡 → 活动详情页
└─ 查看日志 → 活动日志页 → 活动详情页
```

通知权限、麦克风权限和连接失败使用轻量说明弹窗；不要在首页长期占据空间。

## 3. 首页版式

页面左右边距 20；顶部安全区后开始内容。模块之间使用 9–20 的垂直节奏。

1. **状态头**：左侧状态图标与 `Jarvis`，右侧显示“正在感知 / 暂时离线 / 等待连接”。
2. **远端服务器配置**：标题、副标题、设置入口。默认只显示连接摘要。
3. **AI 介入**：标题、副标题、紧凑开关。开关状态必须是真实运行状态。
4. **实时感知**：显示正在识别的文本和最近环境事件；语音优先，点击区域可进入语音输入。
5. **AI 活动**：默认一张主卡。卡片包含短标题、时间、状态和必要操作；可展开来源、门控决定、工具调用、结果与可回滚动作。
6. **活动时间线**：时间列与文本列穿插展示，普通日志不套卡片；待决定、失败或重要结果才使用独立卡片。
7. **查看日志**：进入无限滚动日志页，按游标加载，不一次读取全部数据。

## 4. 视觉基线

```text
Background       #F7F5F0
Surface          #FFFDFA
Text             #302D28
Muted            #79736B
Subtle           #A39C92
Accent           #B96C50
Accent Surface   #F0E4DA
Divider          #E5DFD5
```

英文使用 Roboto，中文使用 Source Han Sans 或系统中文回退。标题 16sp，模块标题 12–13sp，正文 12–14sp，时间和辅助文字 10–11sp。按钮和输入框采用 6–8 的圆角，活动卡 10，弹窗 16；不使用大阴影、渐变或大面积胶囊。

## 5. 活动卡数据绑定

卡片只能展示服务端 Activity 字段，不根据文案猜状态：

```text
title / content       主标题与正文
status                observed / processing / waiting_user / completed ...
created_at             时间
available_actions      接受、暂不、修改、删除、撤销
detail                 展开后的依据、门控、工具和结果摘要
source_refs            原始资料引用及保留状态
```

“暂不”只更新原卡片状态为 `rejected` 或 `ignored`，不新增重复日志行。接受、修改、删除、撤销都携带 Activity ID、版本号和幂等键，由服务端决定下一步。

## 6. 状态与交互

首页至少支持：未配置、连接中、已连接且感知、处理中、等待用户、离线、执行失败。低风险动作可直接执行；高风险动作显示待决定卡。紧急事件只做轻微震动，普通事件不震动。首页摘要优先，用户点击后再展示完整流程。

## 7. 实现交接

- Android 当前入口：`watch-client/app/src/main/java/com/jarvis/watch/MainActivity.java`
- 设计令牌：`docs/DESIGN_SYSTEM.md`
- 活动数据协议：`docs/ACTIVITY_CONTRACT.md`
- 服务端活动读取接口：`GET /api/activities` 与 `GET /api/activities/{event_id}`
- 真机尺寸、字体渲染、触摸热区和续航必须在手表到手并开启 ADB 后复核。
